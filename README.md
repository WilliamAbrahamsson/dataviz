# Premier League Evaluation Prediction Model

This is a AI model which tries to predict the valuation of the player based on fotball performance metrics

## How to run

1. Make Sure you have Python installed
2. Jump into the ```backend``` folder
3. Run the following command: ```pip install -r requirements.txt```
4. Run the backend with this command: ```python app.py```
5. Start a new terminal
6. Jump into the ```frontend``` folder
7. Run the following command ```npm install```
8. Run the frontend with this command: ```npm run dev```
9. Access the localhost port 5173 provided in the terminal
10. Enjoy!

## How to use

**Example Usage:**
Set the season in the top bar to whatever season you like. Click on a team on the map and select a player you want to check out. Expand the window to find detailed information about the player, and change whatever performance metric you want. 
> ***Unchanged performance data is the data the player has performed in the selected season***

Get the prediction evaluation and compare that to your modified performance metric. Find what players are similar in performance to the metrics. 

> ***The similar players are not similar in value, but only in the metrics***

If you want you can try out the search function to search for a specific player.
